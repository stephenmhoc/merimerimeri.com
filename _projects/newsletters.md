Newsletters is a free, open-source service I run on my homelab. It reads the newsletters that land in Gmail, boils each one down to a bullet or two with Claude, and publishes a daily digest at 7 PM as an RSS feed.

I subscribe to too many newsletters. Now I read the gist in my feed reader and open only the ones worth the time.

It runs for me alone, so there's nothing to sign up for. The code is all there if you want to run your own.
