Transcripts is a free, open-source podcast transcript library I run on my homelab. It watches what I play in Overcast, transcribes each episode locally with Whisper on a Mac mini, and makes all of it searchable.

I remember hearing something on a podcast. I never remember which one. Now I search for it.

Transcription runs on my own hardware. Every transcript stays private unless I share a link to it. It also has a read-only MCP server, so an AI assistant can search the library too.
